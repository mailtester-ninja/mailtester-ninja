### What we do

MailTester Ninja verifies email addresses in real time, over SMTP, without ever sending a message and without storing a thing. One request returns a clear verdict: valid, invalid, or uncertain (catch-all). Teams use it to cut bounce rates, protect sender reputation and keep lists clean, at some of the best prices on the market.

- **Nothing stored.** Addresses are processed in memory and never saved. Nothing to leak, nothing to resell.
- **Real time.** Live SMTP checks, not a stale database lookup.
- **Simple.** One GET request. Works from any language, no SDK required.
- **Honest on catch-all.** We label uncertainty instead of guessing "valid".
